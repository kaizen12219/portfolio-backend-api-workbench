# Roadmap

## Milestone 1: API evidence model

- Define role series and stack accent inputs.
- Score projects by role fit, stack fit, and proof depth.
- Return deterministic recommendations from the API.

## Milestone 2: Operations polish

- Add structured logs.
- Add Dockerfile and health-check documentation.
- Add OpenAPI examples for common resume targets.

## Milestone 3: Portfolio integration

- Feed Hugo project front matter from the scoring output.
- Add a small CI job for build and console specs.
- Publish sample JSON fixtures for agencies.
